The problem

Every month, attendance and overtime came in from several sites, each in its own layout. It all had to be copied into payroll and cost sheets, reformatted for the ERP, and turned into a WPS salary file. All by hand. One wrong MOL number or bank account was enough to get a transfer rejected.

What I did

I built a personal macro library that sits inside Excel and works in any workbook. Each step of the payroll cycle became a one-click tool, with a confirmation prompt before anything runs.

The result

Most of the repetitive payroll and ERP preparation now runs on macros. Every MOL number, routing code and bank account is checked before the salary file goes to the bank, so errors get fixed before payday instead of after.
